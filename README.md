# OpenShift Inventory CRUD GitOps Deployment
 
PHP inventory CRUD application with MySQL.
 
## Target
 
- Cluster: compact-baremetal
- Namespace: crud-mysql
- Node: node1
- StorageClass: hostpath-csi-all
- GitOps hub: SNO OpenShift GitOps / Argo CD
 
## Functions
 
- Create inventory item
- Read inventory records
- Edit and update an item
- Delete an item
